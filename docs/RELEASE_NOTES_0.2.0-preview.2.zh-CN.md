# 轻栈 PinoraDesk 0.2.0-preview.2 发布说明

> **状态：Mac 预发布。** 版本标签为 `v0.2.0-preview.2`，应用内版本为 `0.2.0`。本页描述相对 preview.1 的功能变化与验证范围；公开下载是否可用以版本页实际展示的附件和校验文件为准，不表示已完成正式发行验收。

本次重点是更方便的截图、贴图，以及适合长内容和大文件的 JSON 工作区。系统标题栏和品牌栏空白均可按住拖动，按钮与输入区域保留原本操作。当前仅准备 **Apple Silicon／M 系列 Mac（ARM64）** 应用；Windows 工作继续暂停，不提供 Windows 或 Intel Mac 安装包。

## JSON：更大的工作区，统一查找与结构折叠

- **内容区可以真正变大。** 进入 JSON 工具打开较大的工作区，提供“铺满工作区／还原工作区”、可调整的双栏和“专注查看”。窗口变大时显示更多内容，字体独立选择 12／14／16／18px；窄窗口可切换面板。
- **查询不用区分 Key 和 Value。** 按 `⌘F` 输入关键词，统一查询键和值；文本模式覆盖原文和有效结果，对比模式覆盖左右两份内容。通过上一处／下一处定位，查询栏固定在顶部，长内容滚动到底也能继续查找。查询区分大小写；无效 JSON 会提示并退回原文查询。
- **行号和收起／展开。** 左侧显示实际行号，多行对象、数组可逐层折叠或全部折叠。查找到隐藏内容时自动展开对应结构。折叠只改变显示，复制保留原文；编辑折叠内容前会先展开，避免把省略文字写进数据。单行压缩内容可先格式化。
- **格式化、压缩、对比、纠错集中使用。** 数字保留原始写法，避免大整数精度丢失。对比支持差异导航及原文定位；常见语法纠错先展示预览，再由使用者确认。不会猜测缺失值、未闭合字符串或业务意图。

### 几十到上百 MiB 的 JSON，请使用文件模式

普通粘贴文本仍限制为每份 **1 MiB**。更大的内容通过“文件处理”直接选择文件，在后台处理，避免将整份大文件放入编辑框。

- 默认自动识别文件大小，也可切换 **5／10／100／256 MiB** 上限。每份文件最多 256 MiB；对比时左右分别受限，超限提示不会截断数据。
- 支持 UTF-8 JSON、JSONL／NDJSON 的格式化、压缩、对比和受限修复；可查看进度并取消。
- 每段预览最多 64 KiB，显示全文件行号；只折叠当前片段内完整且可确认的结构，不伪造跨片段闭合。
- 文件全局查找默认查询当前结果或草稿，对比时依次查询左右文件。高级选项保留指定文件、原文查找和 JSON Pointer 定位。
- 对比可分页查看、按路径筛选并导出完整差异报告；页面中的前 200 处预览不代表全部差异。完整报告包含有界摘要，长值摘要可能截断，不等于原值全文。
- 可修改结果片段，后台校验整份文件成功后才生成新结果；失败可继续修正或回到上一有效版本。另存使用新文件名，不改写源文件。

大小档位表示允许的文件大小，不代表不同精度。复杂结构、深度、节点数量、临时空间和任务时限仍可能使文件在大小上限内停止并给出提示。未另存的结果和草稿不会因退出应用而长期保存。

## 截图：直接拖选、辅助线和跨屏

- **一次进入选区。** 点击“截图”或使用截图快捷键（当前默认 `Control+Option+A`），直接拖动鼠标框选，不必再次点击“区域截图”。拖动内部可移动选区，八个边角点可调整边界；`Enter`／双击复制退出，`Esc` 取消。
- **对齐辅助线。** 框选前和拖动过程中显示跟随鼠标的横竖虚线；进入标注后自动隐藏，也不会出现在复制、保存、贴图或打印的图片中。
- **实体屏幕间连续拖选。** 2–4 块屏幕分别显示选区覆盖层，可从一块屏幕拖到另一块；松手后在所在屏幕继续标注。单屏保留原流程，更多屏幕可使用“跨屏总览”。真实多屏体验仍有待验收，见下方限制。
- **保留高清与总览两个入口。** 普通截图和实体跨屏按统一像素比例输出；超出安全预算时提示改用主动缩小的“跨屏总览”，不会静默缩小。实际可用大小还受屏幕排列和内存限制。
- **标注与导出。** 提供矩形、椭圆、箭头、画笔、文字、遮挡、马赛克、撤销／重做，以及 PNG／JPEG 保存、本机文字识别和系统打印入口。打印打开系统面板，由使用者确认；不自动发送到打印机。
- **操作可以调整。** 可设置双击、中键、右键与滚轮动作。窗口内控件吸附默认关闭，开启需要系统辅助功能权限；不支持时仍可手动框选。副屏支持像素放大镜和 RGB／HEX 取色。

截图仍需要 macOS 屏幕录制权限。正常授权只针对正在运行的那份应用；按系统提示真正退出并重新打开。应用不会自动重置授权或绕过系统检查。

## 贴图、取色与截图历史

- `F3` 可贴出剪贴板内容或恢复最后关闭的贴图，`Shift+F3` 显示／隐藏全部；部分 Mac 键盘需要同时按 `Fn`。
- 支持图片、文字等贴图，旋转、翻转、缩放、透明度调整、缩略图，以及标注、复制、导出、文字识别和打印。
- 图片贴图按住 `Option` 可放大局部像素并取色；颜色来自当前合成图，不包含桌面背景或系统窗口透明度。
- 贴图可分组管理。主动勾选“记住贴图”后可在重启恢复，当前上限为 3 项／64 MiB；默认不保存。
- 截图历史默认关闭，开启后仅保留本次运行中成功导出的最终图片，最多 8 张／32 MiB。可用逗号、句号或界面按钮回看；退出应用即清空。

**可编辑遮挡不等于不可逆脱敏。** 记住贴图时可能保存原图、原文和可编辑标注。对外分享请使用最终导出图，并检查实际内容。

## 安装与从 preview.1 升级

以下步骤在 preview.2 **正式出现在版本页并提供附件后**使用。准备阶段不要把旧版附件当成新版。

1. 确认电脑为 Apple Silicon／M 系列 Mac。配置目标为 macOS 14 及以上；当前实测设备为 macOS 15.2 ARM64，最低版本仍待实机验收。
2. 打开[公开下载页](https://github.com/SleepyBytepp/pinoradesk-downloads/releases)，确认标签为 `v0.2.0-preview.2`，下载该版本的应用 DMG 或 ZIP。使用短文件名 `PinoraDesk.dmg`／`PinoraDesk.zip`，以实际附件为准；GitHub 自动生成的 `Source code` 不是应用安装包。
3. 对照同一版本的 `SHA256SUMS.txt` 校验下载文件。校验不一致时重新下载，不继续安装。校验一致不等于 Apple 公证。
4. 升级前先另存正在处理的 JSON、图片和其他需要保留的内容；从轻栈菜单选择“退出轻栈”。只关闭窗口通常是隐藏，不是真正退出。
5. DMG 打开后将 `PinoraDesk.app` 放入“应用程序”；ZIP 先完整解压，再将应用放入同一位置。替换前保留需要的旧版副本和数据备份，不要同时运行多个副本。
6. 弹出磁盘映像，从“应用程序”打开安装好的那一份。当前没有自动更新机制，不需要安装 Node、Rust 或工程文件。
7. 首次打开可能遇到开发者验证提示：确认来源及校验后，按系统正常的单应用放行流程处理。当前应用**未公证**；若出现“已损坏”“恶意软件”或“会损坏电脑”等提示，先核对下载并反馈，不关闭整机安全检查。
8. 打开设置确认快捷键。截图如提示权限，在系统设置中允许正在运行的应用，并按系统要求退出重开；应用完全退出时快捷键不会生效。

如有问题，可先查阅[安装说明](INSTALL.zh-CN.md)、[常见问题](FAQ.zh-CN.md)和[完整使用指南](USER_GUIDE.zh-CN.md)。preview.1 历史说明仍保留，请核对文档与附件的适用版本。

## 已知限制与验证范围

- **仍是开发预览版。** 仅准备 Mac ARM64 应用，尚未完成 Apple 公证和跨机器安装升级验收。Windows 暂停，Intel Mac 无对应包。
- **窗口验证范围。** 品牌栏空白基本拖动已由用户实测确认。后台首按、20 轮连续拖动、实际铺满矩形、系统全屏／最小化、多屏及移除显示器矩阵仍未全部验收；基本拖动确认不等于完整矩阵通过。
- **跨屏不是所有设备都已验证。** 实体多屏连续拖选、混合 DPI、独立 Spaces、休眠唤醒与真实第三方控件吸附仍需设备验证。各屏分别取帧，动态图像可能有时间差。真实打印机出纸也尚未验证。
- **首次大文本显示仍可能短暂停顿。** 约 1 MiB、48,656 行的合成组件测试首次显示约 0.2 秒，单次写入观察到 169 ms 主线程长任务；不能称为绝对无卡顿。10 轮滚动及组件尺寸变化未观察到超过或等于 50 ms 的长任务，行号最多渲染 34 个可见节点。测试时有并发构建负载，结果不是所有设备与数据的性能保证；更大内容请使用后台文件模式。
- **自动检查与实机体验分开记录。** 当前候选已通过类型检查、101 项前端单元、338 项 Rust 检查、24 个合成界面场景的 480 项检查及补充品牌栏拖动组件的 13 项检查，5 项已有忽略项仍未执行；Mac ARM64 构建通过；最终候选本地签名、DMG、ZIP 完整性、解包后签名及二进制一致性检查通过，这不等于 Apple 公证或跨机器安装验收。远程 CI 仍有历史失败记录，尚未以本候选重新验证，也不代表 Windows 已构建成功。
