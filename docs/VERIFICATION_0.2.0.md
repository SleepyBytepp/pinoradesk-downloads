# PinoraDesk 0.2.0 验证说明

## v0.2.0-preview.2 当前验证范围（2026-11-11）

状态为 **Mac 预发布**，面向 Apple Silicon／ARM64。已实际使用的开发设备为 macOS 15.2；最低 macOS 14 与其他机器仍需实测。当前页面不宣称公开发布已经成功，也不把构建或合成测试当作完整实机验收。

| 验证层级 | 已取得结果 | 边界 |
|---|---|---|
| 前端单元 | 101 项通过 | 数据模型与前端逻辑 |
| Rust release 库 | 338 项通过，5 项原有忽略项未执行 | 忽略项不算通过 |
| 全量合成页面 | 24 个场景，480 项通过 | 隔离浏览器、合成图像与模拟原生接口 |
| Mac 品牌栏拖动组件 | 补充 13 项通过 | 按下即调用拖动、控件排除与错误反馈；非真实窗口手感 |
| 静态与构建 | 类型、格式、严格 Clippy、Mac ARM64 构建通过 | 不等于跨机器安装验收 |
| 最终安装附件 | 本地签名、DMG 校验、ZIP 完整性、解包后签名及二进制一致性通过 | 不等于 Apple 公证或跨机器安装验收 |
| JSON 工作区 | 查询固定、折叠定位、窄窗口、错误恢复等合成检查通过 | 不代表所有原生窗口与硬件场景 |

### 性能测量的含义

约 1 MiB、48,656 行合成 JSON 首次显示约 0.2 秒，观察到 169 ms 主线程长任务。10 轮滚动及组件尺寸变化未观察到 ≥50 ms 长任务，行号最多渲染 34 个可见节点。测量时存在并发构建负载，不是所有设备与数据的保证，不能称为绝对无卡顿。几十到上百 MiB 的 JSON 使用后台文件模式；每份上限 256 MiB，按段显示和编辑。

### 实现后仍需实机验收

- 品牌栏空白基本拖动已由用户实测确认；后台首按、20 轮连续拖动、实际铺满／还原矩形、系统全屏／最小化、多屏及移除显示器矩阵仍未全部验收。
- 实体多屏连续拖选、混合 DPI、独立 Spaces、休眠唤醒、完整权限撤回及受保护内容。
- 真实第三方控件几何吸附、打印机出纸、OCR 复制粘贴、贴图重启恢复及多 Space。
- 跨机器下载后的 Gatekeeper、正常录屏授权、安装／升级／卸载与 Apple 公证。
- 长时间资源压力、全部插件组合、Windows 原生功能及 Windows 安装包。Windows 当前暂停；没有 Intel Mac 包。

自动剪贴板采集、截图历史、记住贴图及 WASM 默认关闭。原生系统授权、真实图像和用户操作有独立边界，不能由模拟接口测试替代。当前不声称与 Snipaste Mac 免费版完全一致，也不兼容 uTools 商店和私有协议。

### 远程 CI

历史远程检查包含 Mac HTTPS 测试夹具超时与 Windows Rust lint 失败。Mac 夹具已经本地修复并回归；新的远程结果只能以对应提交的实际运行记录为准，不能用本地通过替代远程通过。公开下载站只提供发行资料，使用者不需要私有源码访问权限。
