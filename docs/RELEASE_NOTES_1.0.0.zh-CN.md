# 轻栈 PinoraDesk 1.0.0 发布说明

本次版本号为1.0.0，提供Mac ARM64的PinoraDesk.dmg和PinoraDesk.zip。源码继续私有；公开仓库仅提供应用附件和说明资料。发布状态以GitHub版本页实际附件为准。

## 相对0.2.0预览版的主要变化

- JSON改用CodeMirror编辑器：更适合较长文本，保留行号、折叠、固定全局查询、大工作区和分段文件处理；增加草稿恢复与对比细节改进。
- 滚动长截图：逐段采集、重叠识别、手动修正、接缝预览、撤销和取消；操作栏固定，预览失败可重试。
- 桌面取色、可选持久截图记录，以及图片／文件剪贴板会话历史。
- 文件正文查找：限定授权目录、类型筛选、首处行号和上下文、停止及重查。
- 时间工具实时显示当前时间及秒／毫秒时间戳，支持切换时区和复制填入。
- 设置与手工片段迁移：逐项预览、冲突提示、导入前备份和事务恢复。
- 手动应用更新客户端：独立签名、流式校验、取消、主动打开。真实可信更新渠道尚未配置。
- 窗口外观：取消原生标题栏下重复圆角和描边，内容顶部平直衔接；保留品牌区立即拖动和窗口缩放。

## 保留的范围与限制

本包仍是固定本地开发签名，未Apple公证。Windows暂停、无Intel包；混合DPI／Spaces、跨机器安装升级、系统权限和部分原生操作仍待实测。长截图需要手动滚动，上百MB JSON仍采用分段处理，不提供全文自由编辑。不声称完整复刻Snipaste或兼容uTools插件商店。
