# 轻栈 PinoraDesk 0.2.0 开发预览版

这是供试用的 **Mac ARM64 开发预览版**，不是稳定版或已公证发行版。应用与用户文档放在独立公开下载仓库；源码仍私有。应用内版本为0.2.0。

## 下载与安装

- **DMG：** 下载`PinoraDesk-0.2.0-preview.1-macos-arm64.dmg`，打开后把App拖到Applications。
- **ZIP：** 下载`PinoraDesk-0.2.0-preview.1-macos-arm64.zip`，完整解压并把App放入“应用程序”。
- 配置目标macOS14+，已实际验证macOS15.2 ARM64；Intel和Windows暂未提供包。
- 校验文件：`SHA256SUMS.txt`。自动生成的`Source code`附件是源码，不是应用。

当前使用固定本机开发签名，未获Apple Developer ID公证。首次打开请按系统正常的单应用例外流程处理；若是损坏/恶意警告，先停用并核对，不关闭系统安全检查。

## 当前功能

快捷键应用搜索、JSON格式化/对比/纠错、计算器/时间戳/UUID/Base64；区域截图、标注、最终图OCR、PNG/JPEG、贴图及分组；文本剪贴板和片段JSON导入；Mac文件搜索；本地声明式插件、默认关闭的WASM及手动信任的签名来源。

自动采集、截图历史、贴图记住与WASM均默认关闭。贴图保存含原图/原文与可编辑标注，遮挡不是不可逆脱敏。

## 使用提示

启动器默认Option+Space；截图Control+Option+A；贴图F3（可能需Fn）。关闭窗口通常只隐藏，菜单栏“退出轻栈”才真正退出，退出后全局快捷键停止。

## 验证与已知问题

现有Mac包已做本机构建、固定签名与启动验证；DMG/ZIP封装后已完成解包、只读挂载、执行权限、签名与摘要核对。原App未改动，二进制保留开发编译诊断路径；跨机器下载后的Gatekeeper与完整安装权限流程未验证。

两平台前端CI已通过；Mac有3项本地HTTPS测试夹具就绪超时，Windows有条件编译相关Rust lint问题，因此不能称完整CI通过。跨屏/混合DPI、元素识别、指针捕获、打印及部分高级交互仍待补齐。Windows不能因CI中有任务就当作应用已可用。
