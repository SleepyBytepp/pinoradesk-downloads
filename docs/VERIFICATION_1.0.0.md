应用采用既有固定本地开发证书。DMG／ZIP检查包括签名完整性、DMG内部校验、ZIP CRC、解包后主程序摘要及原包未被修改。通过封装检查不等于跨机器Gatekeeper、屏幕录制权限和安装升级体验通过。
